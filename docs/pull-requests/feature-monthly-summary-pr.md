## Summary
- Adds a new `/summary` page with a month-selectable overview of total spend, transaction count, average per transaction, and a category breakdown table
- Builds out the previously empty `/settings` page with editable profile (name), currency preference, theme toggle, and a danger zone section
- Extends all navigation surfaces (top navbar, sidebar, bottom nav) with a Summary link

## Changes

**New pages & loading states**
- `app/(app)/summary/page.tsx` — server component; validates `?year`/`?month` search params with Zod, parallel-fetches summary and categories, renders `SummaryView`
- `app/(app)/summary/loading.tsx` — skeleton for summary page
- `app/(app)/settings/page.tsx` — server component; fetches user by session ID, renders `SettingsView`
- `app/(app)/settings/loading.tsx` — skeleton for settings page

**UI components**
- `components/summary/SummaryView.tsx` — stat cards, category breakdown table, empty state, month label
- `components/summary/MonthSelector.tsx` — client `Select` that pushes `?year=&month=` to the router
- `components/settings/SettingsView.tsx` — Profile card (name edit), Preferences card (currency + theme), Danger Zone card

**Service & action layer**
- `lib/services/userService.ts` — `fetchUserById` wrapped in `React.cache()`
- `lib/actions/user.ts` — `updateProfileAction` and `updateCurrencyAction`; both authenticate via `requireSession()` and re-validate with `UpdateUserSchema`

**Navigation**
- `components/layout/AppNavbar.tsx` — Summary added to desktop center links and mobile drawer
- `components/layout/AppSidebar.tsx` — Summary added with `CalendarDays` icon
- `components/layout/BottomNav.tsx` — Summary added as fifth tab

## How to test

1. Sign in and navigate to `/summary` — confirm it loads with the current month's data
2. Use the month selector dropdown to pick a prior month — confirm the page re-renders with correct data for that month
3. Navigate to a month with no expenses — confirm the empty state card and "Add an expense" button appear
4. Navigate to `/settings` — confirm the Profile card shows your name and email
5. Edit the display name and click **Save Changes** — confirm a success toast appears and the name updates
6. Change the currency dropdown and click **Save Currency** — confirm a success toast appears
7. Change the Theme select — confirm the app theme switches immediately without a page reload
8. Confirm the Summary link is active-highlighted in the top navbar, sidebar, and bottom nav when on `/summary`

## Notes
- The bottom nav now has 5 tabs; `docs/ui.md` specifies a maximum of 4. This was an explicit user request and is a known deviation from the spec.
- Delete Account in the Danger Zone is a visual placeholder (button is disabled). Full account deletion is out of scope for this branch.
- `/settings` is a single combined page rather than the `/settings/profile` + `/settings/preferences` sub-page structure specified in `docs/routing.md`. This is a known deviation kept for simplicity.
- `getMonthlySummary` in `summaryService.ts` is not wrapped in `React.cache()` — pre-existing issue, not introduced here.
