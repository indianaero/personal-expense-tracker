## How to test
1. Sign in and navigate to `/expenses`
2. Click the FAB (bottom-right) to open the create expense modal; submit a valid expense
3. Confirm the expense appears in the list without a full page reload (optimistic update)
4. Click an expense row to open the edit modal; update a field and save
5. Delete an expense via the delete modal; confirm it is removed from the list
6. Navigate to `/dashboard` and confirm the monthly summary reflects the created expenses
7. Run `npm test` — all 52 tests should pass
