## Summary
- Implements the complete authentication flow — credentials-based sign-in/register and Google OAuth — using NextAuth v4 with JWT sessions
- Migrates the data layer from MongoDB to Supabase (PostgreSQL) and establishes Row Level Security policies
- Adds edge middleware to protect all app routes by default, with an explicit allowlist for public paths
- Introduces the full documentation suite covering auth, security, routing, UI conventions, error handling, data mutation, and best practices

## How to test
1. Copy `.env.example` to `.env.local` and fill in Supabase, NextAuth, and Google OAuth credentials
2. Run `npm run dev` and navigate to `http://localhost:3000` — should redirect to `/login`
3. Register a new account via the credentials form; confirm redirect to `/dashboard`
4. Sign out and sign back in with the same credentials
5. Attempt to access `/dashboard` while unauthenticated — should redirect to `/login`
6. Sign in with Google — confirm the user row is auto-provisioned in the `users` table
7. Confirm `SUPABASE_SERVICE_ROLE_KEY` does not appear in the browser bundle (`ANALYZE=true npm run build`)
8. Verify Supabase RLS policies are active by attempting a direct query with the anon key — should return no rows
